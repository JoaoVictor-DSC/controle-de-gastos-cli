# 💰 Controle de Gastos CLI

Aplicação de linha de comando em Python para registrar despesas pessoais, consultar totais por categoria e visualizar os gastos em gráficos.

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar manipulação de arquivos JSON, organização de código em módulos, tratamento de erros e visualização de dados com Python. Os dados ficam salvos em um arquivo local, então nada se perde ao fechar o programa.

## ✨ Funcionalidades

- Adicionar despesas (valor, categoria, descrição e data)
- Listar todas as despesas registradas
- Ver o total gasto por categoria
- Filtrar despesas por mês
- Gerar gráfico de pizza com os gastos por categoria
- Salvamento automático em arquivo JSON

## 🛠️ Tecnologias utilizadas

- Python 3
- JSON (armazenamento de dados)
- Matplotlib (gráficos)
